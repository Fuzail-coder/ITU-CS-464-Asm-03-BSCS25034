# ITU-CS-464-Asm-03-BSCS25034
5 level rolling ball game 


In this game I made 5 levels of maze in which coins are spawned and enemies walk.
Here I have 3 crushers in game.
At each level player has to collect coins and after collecting them player will get to open the door and collect star and he will win the game. Wining every level takes you to next level. Every level have a different timer.
 Level 1:
 Easy Map 
 Only coins spawn
 3 enemies 
 3 crushers

 Level 2:
 Bigger Map
 Speed Boost power up which accelerates to 1.5x for 10 seconds
 More coins to collect

 Level 3:
 2 cone hazars
 health power up which will be only acquired when 1 life remains
 speed boosters
 More coins target

 Level 4:
 More Coins target
 More hazard cones
 Chasing enemies
 4 enemies

 Level 5:
 Shield power up which protects only once and make a shield around player
 Bigger coins target
